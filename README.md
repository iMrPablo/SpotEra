## 📖 معرفی

**اسپاتیرا (SpotEra.ir)** یک پیام‌رسان مدرن و سبک تحت وب است که توسط **آقای پابلو** طراحی و توسعه یافته است. این سیستم امکان ارسال پیام‌های متنی، تصویری، ویدیویی و فایل‌های مختلف را به صورت خصوصی، گروهی و کانالی فراهم می‌کند. اسپاتیرا با بهره‌گیری از معماری MVC (Model-View-Controller) کدنویسی شده است که باعث خوانایی، قابلیت نگهداری و توسعه آسان‌تر پروژه می‌شود.

### 📜 تاریخچه پروژه

- **۱۴۰۴**: انتشار نمونه اولیه (Prototype) اسپاتیرا به عنوان یک ایده آزمایشی
- **۱۴۰۵**: آغاز توسعه رسمی و حرفه‌ای پروژه پس از یک سال بررسی و بازخورد کاربران
- **حال حاضر**: تبدیل به یک پیام‌رسان کامل با امکانات پیشرفته

این پروژه پس از یک سال توسعه مداوم، اکنون به یک پلتفرم پیام‌رسانی پایدار و امن تبدیل شده است که آماده استفاده در محیط‌های واقعی است.

### ✨ چرا اسپاتیرا؟

- 🚀 **سبک و سریع**: بدون نیاز به دیتابیس‌های سنگین، استفاده از فایل‌های JSON
- 🔒 **امن**: احراز هویت امن، رمزنگاری پسوردها، محافظت در برابر حملات رایج
- 📱 **واکنش‌گرا**: رابط کاربری مدرن و سازگار با موبایل و دسکتاپ
- 🌙 **تم تاریک/روشن**: قابلیت تغییر پوسته به صورت آنی
- 💬 **چندمنظوره**: پشتیبانی از چت خصوصی، گروه و کانال
- 📎 **اشتراک‌گذاری فایل**: ارسال تصاویر، ویدیوها و فایل‌های مختلف
- ✅ **تیک خوانده‌شدن**: نمایش وضعیت مشاهده پیام‌ها
- 🔔 **اعلان‌ها**: سیستم اعلان برای پیام‌های جدید

## 🎯 امکانات و ویژگی‌ها

### مدیریت کاربران
- ثبت‌نام و ورود امن با نام کاربری و رمز عبور
- پروفایل کاربری با امکان آپلود آواتار
- ویرایش اطلاعات شخصی (نام، نام کاربری، رمز عبور)
- جستجوی کاربران برای شروع چت

### انواع چت
- **چت خصوصی**: مکالمه دو نفره با تیک خوانده‌شدن
- **گروه‌ها**: ایجاد گروه با اعضای متعدد و مدیریت ادمین‌ها
- **کانال‌ها**: کانال‌های اطلاع‌رسانی با مدیران مشخص

### پیام‌رسانی
- ارسال پیام‌های متنی با پشتیبانی از ایموجی
- اشتراک‌گذاری تصاویر (JPG, PNG, GIF, WebP)
- ارسال ویدیو (MP4, WebM)
- ارسال فایل‌های عمومی (PDF, DOC, ZIP, etc.)
- نمایش پیش‌نویس لینک‌ها (Open Graph)
- وضعیت تایپ کردن (Typing Indicator)
- تیک двойی برای پیام‌های خوانده‌شده

### داشبورد مدیریت
- پنل مدیریت کامل برای ادمین‌ها
- مشاهده لیست تمام کاربران
- مدیریت کاربران (ویرایش، حذف، انتقال به ادمین)
- آمار سیستم (تعداد کاربران، پیام‌ها، فضای مصرفی)
- مدیریت فایل‌های آپلودشده

### تجربه کاربری
- رابط کاربری فارسی و راست‌چین (RTL)
- تم تاریک و روشن با قابلیت تغییر آنی
- طراحی Material Design مدرن
- انیمیشن‌های نرم و جذاب
- کاملاً واکنش‌گرا برای موبایل و تبلت

## 🏗️ ساختار پروژه (MVC)

این پروژه بر اساس الگوی معماری **MVC (Model-View-Controller)** سازماندهی شده است:

```
spatira/
├── app/                      # پوشه اصلی برنامه
│   ├── core/                 # هسته مرکزی
│   │   ├── Database.php      # کلاس اتصال به دیتابیس (JSON)
│   │   ├── Controller.php    # کلاس پایه کنترلر
│   │   ├── Model.php         # کلاس پایه مدل
│   │   ├── View.php          # کلاس مدیریت ویو
│   │   └── Router.php        # مسیریابی درخواست‌ها
│   │
│   ├── controllers/          # کنترلرها
│   │   ├── AuthController.php    # کنترلر احراز هویت
│   │   ├── ChatController.php    # کنترلر چت و پیام‌ها
│   │   ├── UserController.php    # کنترلر کاربران
│   │   ├── AdminController.php   # کنترلر پنل مدیریت
│   │   └── ApiController.php     # کنترلر API
│   │
│   ├── models/             # مدل‌ها
│   │   ├── User.php            # مدل کاربر
│   │   ├── Message.php         # مدل پیام
│   │   ├── Chat.php            # مدل چت/گروه/کانال
│   │   ├── Upload.php          # مدل آپلود فایل
│   │   └── Config.php          # مدل پیکربندی
│   │
│   └── views/              # ویوها (قالب‌ها)
│       ├── layouts/            # لی‌اوت‌های اصلی
│       │   ├── header.php
│       │   └── footer.php
│       ├── auth/               # صفحات احراز هویت
│       │   ├── login.php
│       │   └── register.php
│       ├── chat/               # صفحات چت
│       │   ├── index.php
│       │   └── conversation.php
│       ├── dashboard/          # پنل مدیریت
│       │   └── index.php
│       └── partials/           # بخش‌های مشترک
│
├── public/                   # فایل‌های عمومی (دسترسی مستقیم)
│   ├── assets/               # منابع استاتیک
│   │   ├── css/              # فایل‌های CSS
│   │   │   ├── style.css     # استایل اصلی
│   │   │   ├── dark.css      # تم تاریک
│   │   │   └── responsive.css # استایل واکنش‌گرا
│   │   └── js/               # فایل‌های JavaScript
│   │       ├── app.js        # جاوااسکریپت اصلی
│   │       ├── chat.js       # منطق چت
│   │       └── admin.js      # منطق پنل مدیریت
│   ├── uploads/              # فایل‌های آپلودشده کاربران
│   └── avatars/              # آواتار کاربران
│
├── data/                     # داده‌های JSON (خارج از public)
│   ├── users.json            # اطلاعات کاربران
│   ├── messages.json         # پیام‌ها
│   ├── chats.json            # چت‌ها، گروه‌ها، کانال‌ها
│   ├── reads.json            # وضعیت خوانده‌شدن پیام‌ها
│   ├── config.json           # تنظیمات سیستم
│   └── previews.json         # کش پیش‌نمایش لینک‌ها
│
├── config/                   # فایل‌های پیکربندی

│
├── index.php                 # نقطه ورود اصلی (Router)
├── .htaccess                 # تنظیمات Apache
└── README.md                 # همین فایل!
```

### توضیح لایه‌های MVC

#### 1. **Model (مدل)**
مدل‌ها مسئول مدیریت داده‌ها و ارتباط با لایه ذخیره‌سازی هستند:
- عملیات CRUD (ایجاد، خواندن، به‌روزرسانی، حذف)
- اعتبارسنجی داده‌ها
- ارتباط با فایل‌های JSON

#### 2. **View (ویو)**
ویوها مسئول نمایش داده‌ها به کاربر هستند:
- قالب‌های HTML
- دریافت داده از کنترلر
- رندر کردن خروجی نهایی

#### 3. **Controller (کنترلر)**
کنترلرها واسط بین مدل و ویو هستند:
- دریافت درخواست‌های کاربر
- فراخوانی مدل‌ها برای پردازش داده
- انتخاب ویو مناسب برای نمایش

## 🚀 نصب و راه‌اندازی

### روش اول: دانلود از Releases (پیشنهادی)

1. به بخش **[Releases](https://github.com/your-username/SpotEra/releases)** در مخزن گیت‌هاب پروژه مراجعه کنید.
2. آخرین نسخه پایدار را دانلود کنید (فایل `SpotEra-vX.X.X.zip`).
3. فایل زیپ را در هاست یا لوکال هاست خود استخراج (Extract) کنید.
4. مراحل زیر را برای تکمیل نصب دنبال کنید.

> 💡 **نکته:** این روش برای کاربران عادی و نصب سریع توصیه می‌شود.

### روش دوم: کلون کردن از گیت‌هاب (برای توسعه‌دهندگان)

```bash
git clone https://github.com/your-username/SpotEra.git SpotEra
cd SpotEra
```

> 💡 **نکته:** این روش برای توسعه‌دهندگان و کسانی که می‌خواهند در پروژه مشارکت کنند مناسب است.

### پیش‌نیازها

- **PHP**: نسخه 7.4 یا بالاتر (توصیه: 8.x)
- **Web Server**: Apache یا Nginx
- **Extensions**: `json`, `mbstring`, `fileinfo`
- **Mod Rewrite**: فعال بودن ماژول rewrite در Apache

### مراحل پیکربندی اولیه

پس از دانلود و استخراج فایل زیپ، مراحل زیر را انجام دهید:

#### 1. تنظیم مجوزهای دسترسی

```bash
chmod -R 755 data/
chmod -R 755 public/uploads/
chmod -R 755 public/avatars/
chown -R www-data:www-data data/ public/uploads/ public/avatars/
```

> **نکته برای کاربران ویندوز:** مطمئن شوید که پوشه‌های ذکر شده در قسمت Security تب Properties، دسترسی Full Control را به کاربر IUSR یا Application Pool Identity دارند.

#### 2. پیکربندی وب‌سرور

**Apache (.htaccess موجود است):**

```apache
RewriteEngine On
RewriteCond %{REQUEST_FILENAME} !-f
RewriteCond %{REQUEST_FILENAME} !-d
RewriteRule ^(.*)$ index.php?url=$1 [QSA,L]
```

**Nginx:**

```nginx
server {
    listen 80;
    server_name yourdomain.com;
    root /path/to/SpotEra/public;
    index index.php;

    location / {
        try_files $uri $uri/ /index.php?url=$query_string;
    }

    location ~ \.php$ {
        fastcgi_pass unix:/var/run/php/php8.1-fpm.sock;
        fastcgi_index index.php;
        include fastcgi_params;
        fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
    }

    location ~ /\. {
        deny all;
    }

    location ~* \.(json|log|md)$ {
        deny all;
    }
}
```

#### 3. بازدید از صفحه نصب

مرورگر را باز کرده و به آدرس زیر بروید:

```
http://yourdomain.com/install
```

فرم نصب را پر کنید:

- رمز عبور ادمین

#### 4. تکمیل نصب

پس از ثبت اطلاعات، سیستم به صورت خودکار:

## 🔒 امنیت

### ویژگی‌های امنیتی پیاده‌سازی‌شده

1. **رمزنگاری پسوردها**: استفاده از `password_hash()` با الگوریتم bcrypt
2. **محافظت CSRF**: توکن‌های امنیتی برای فرم‌ها
3. **XSS Prevention**: استفاده از `htmlspecialchars()` برای خروجی‌ها
4. **SQL Injection**: عدم استفاده از SQL (ذخیره‌سازی JSON)
5. **File Upload Security**:
   - بررسی نوع فایل
   - تغییر نام فایل‌ها
   - محدودیت حجم
   - غیرفعال کردن اجرای PHP در پوشه آپلود
6. **Session Security**:
   - Session Regeneration
   - HTTP Only Cookies
   - Secure Cookies (در HTTPS)
7. **Access Control**:
   - بررسی دسترسی ادمین
   - محافظت از مسیرهای حساس
8. **Directory Protection**:
   - فایل `.htaccess` برای مسدود کردن دسترسی مستقیم
   - جلوگیری از List کردن دایرکتوری‌ها

### توصیه‌های امنیتی اضافی

- ✅ حتماً از HTTPS استفاده کنید
- ✅ فایل‌های JSON را در پوشه‌ای خارج از `public` قرار دهید
- ✅ به‌روزرسانی منظم PHP و سرور
- ✅ پشتیبان‌گیری دوره‌ای از داده‌ها
- ✅ محدود کردن دسترسی به پنل مدیریت با IP Whitelist
